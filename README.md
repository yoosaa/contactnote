# Contactnote

Contactnote は、小規模事業者向けの問い合わせ・対応管理メモツールです。

受けた連絡や問い合わせを、未着手から対応完了まで抜け漏れなく管理できるようにすることを目的としています。

本格的な CRM ではなく、小規模店舗・個人運営・フリーランス・小規模チームでも扱いやすい軽量な問い合わせ管理ツールとして設計しています。

## Demo Scope

初期 MVP では、以下の操作に対応しています。

- 問い合わせの新規作成
- 問い合わせ一覧
- 問い合わせ詳細
- 問い合わせ編集
- 問い合わせ削除
- ステータス変更
- ステータスフィルタ
- 連絡チャネルフィルタ
- localStorage への保存
